# Hz Switcher
اپلیکیشن اندروید فارسی برای تغییر نرخ نوسازی نمایشگر با دسترسی Root (60/90/120Hz)، نمایش نرخ فعلی، ذخیره تنظیمات اولیه و بازگردانی با Auto.

ساخت خودکار APK از طریق GitHub Actions انجام می‌شود. پس از اتمام workflow، از Actions > Build Android APK > Artifacts فایل Hz-Switcher-debug-apk را دانلود کنید.

نیازمندی: Android 8.0+، JDK 17، Gradle 8.9 و Android SDK 35.
